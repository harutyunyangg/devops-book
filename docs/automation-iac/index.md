# Automation և IaC

**IaC** (**I**nfrastructure **a**s **C**ode՝ «ենթակառուցվածքը՝ որպես կոդ») մոտեցումը թույլ է տալիս սերվերների կարգավորումը, ծրագրերի տեղադրումը և միջավայրի ստեղծումը նկարագրել կոդով ու ավտոմատ կիրառել։ Սա DevOps-ի «ամեն ինչ կոդով» սկզբունքի գործնական մարմնավորումն է. ավտոմատացումը նվազեցնում է ձեռքի աշխատանքը, **config drift**-ը (սերվերների հեռացումը միմյանցից) և մարդկային սխալը։

## Թեմաներ

- [Ansible](ansible.md) — սերվերային կոնֆիգուրացիայի ավտոմատացում playbook-ներով ու roles-երով. inventory, modules, handlers, փոփոխականներ և `.j2` (Jinja2) templates։
- [YAML](yaml.md) — DevOps-ի կոնֆիգուրացիաների ձևաչափը. null/boolean, folded/literal տեքստեր (`>`/`|`), anchor/alias/merge (`&`/`*`/`<<:`), մեկնաբանություններ և փաստաթղթի բաժանարարներ (`---`/`...`)։
- Terraform — շուտով (cloud-ի IaC)։
