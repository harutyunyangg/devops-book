# Linux

Linux-ը DevOps-ի հիմքն է. production workload-ների մեծ մասը գործում է Linux միջավայրում։ Այս բաժնում կսովորենք համակարգը դիտել որպես պրոցեսների, ֆայլերի, ցանցային socket-ների և ծառայությունների համակարգ։

## Թեմաներ

- [Processes](processes.md) — ծրագրերի գործարկում, դիտարկում և անվտանգ դադարեցում։
- Filesystem — շուտով։
- systemd — շուտով։
