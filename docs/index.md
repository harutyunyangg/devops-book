# DevOps ուսումնական ձեռնարկ

Այս գիրքը կառուցում ենք սովորելու հետ զուգահեռ. յուրաքանչյուր թեման ունի տեսություն, իրական հրամաններ, վերարտադրելի փորձարկում և production մտածողություն։

## Գլոբալ էջեր

- [Linux](linux.md) — Processes, Bash Scripting, Cgroups, Networking, Firewall, Filesystem, Special Bits։
- [Automation և IaC](automation-iac.md) — Ansible և YAML։
- [Containers](containers.md) — Docker և կոնտեյներներ։
- [Python](python.md) — Virtual Environments (venv), մեթոդներ և type hints, SQL placeholders և injection-ից պաշտպանություն։
- [Security, Observability և Cloud](security.md) — Least Privilege։
- [Բառարան](glossary.md) — տերմինների բառարան։


## Ինչպես օգտագործել

1. Ընտրիր մեկ փոքր թեմա։
2. Նախ կարդա նպատակներն ու տեսությունը։
3. Կատարիր lab-ը քո Linux VM-ում կամ Docker կոնտեյներում։
4. Փորձիր պատասխանել հարցազրույցի և ինքնաստուգման հարցերին։
5. Զրույցի վերջում խնդրիր թարմացնել գիրքը՝ պահպանելով repository-ի `AGENTS.md` աշխատանքային կանոնները։

## Ճանապարհային քարտեզ

| Փուլ | Թեմաներ | Արդյունք |
| --- | --- | --- |
| 1 | Linux, shell, processes, filesystem, systemd | Կարողանաս ախտորոշել Linux հոսթ |
| 2 | TCP/IP, DNS, HTTP, TLS, firewalls | Կարողանաս հետևել խնդրի ցանցային շղթային |
| 3 | Git, CI/CD, IaC (Ansible), deployments | Կարողանաս կառուցել անվտանգ pipeline և ավտոմատացնել սերվերային կարգավորումները |
| 4 | Containers, Kubernetes | Կարողանաս փաթեթավորել և գործարկել ծառայություն |
| 5 | Cloud, security, monitoring, incident response | Կարողանաս շահագործել ծառայությունը production-ում |
